# 🏢 HR System

A modern Human Resources (HR) management system built with **Laravel**, **Livewire**, and **Laravel Jetstream**.

---

## 🚀 Features

- 🔐 **User Authentication**: Secure Login & Registration.
- 👥 **Team Management**: Integrated Jetstream Teams for managing HR teams, roles, and permissions.
- ⚡ **Reactive UI**: Built with Laravel Livewire for fast, interactive user experiences.
- 🗄️ **Database Management**: MySQL integration for managing system users and team data.

---

## 🛠️ Tech Stack

- **Framework**: Laravel 11
- **Fullstack / UI**: Livewire, Blade, Tailwind CSS
- **Auth & Teams**: Laravel Jetstream
- **Database**: MySQL
- **Local Environment**: Laravel Herd
